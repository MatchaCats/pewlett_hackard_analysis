# pewlett_hackard_analysis

Project Overview
This project involved three key components:

Data Modeling: Designing a relational database schema based on six CSV files and sketching an Entity Relationship Diagram (ERD).
Data Engineering: Building SQL tables, defining data types, keys, and constraints, and importing the CSV data into the tables.
Data Analysis: Writing SQL queries to answer specific business questions about the data, such as identifying managers, department details, and unique employee traits.

Key Features
Entity Relationship Diagram (ERD): Visual representation of the database structure.
Schema Design: Accurate table definitions with primary and foreign keys, data types, and constraints to ensure integrity.
Data Importation: Seamless integration of raw CSV data into a SQL database.
Insightful Queries: Analytical SQL queries to extract meaningful insights from the dataset.

Insights Gained
The analysis answered questions like:

Who were the managers of each department during the 1980s and 1990s?
What were the hiring patterns, and who were hired in 1986?
Which employees shared common last names, and how often?
Insights into departments like Sales and Development and their employees.

Technologies Used
SQL: Database design, management, and querying.
Entity Relationship Diagram Tools: For schema modeling.
CSV: Raw data format for importation
